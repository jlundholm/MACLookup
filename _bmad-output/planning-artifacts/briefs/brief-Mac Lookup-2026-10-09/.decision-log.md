## 2026-10-09 — Research grounding

- **Competitor scan:** "MAC Address Converter & OUI Lookup" 4 formats (colon, hyphen, Cisco-dot, no-separator); input strips `: . - space` and requires exactly 12 hex digits. OUI lookup is a remote call to `api.macvendors.com` (`host_permissions: https://api.macvendors.com/*`); only other permission is `clipboardWrite`. Light-only UI, no dark mode. 0 ratings, 17 users.
- **Competitor scan:** "MAC Address Converter" (5.0★, 245 users) — no OUI lookup; "Lookup MAC Address" (3.6★) — broken/stale API; NetworkCalc bundles OUI lookup inside a broader tool.
- **OUI data measured from standards-oui.ieee.org (2026-10-10):** MA-L `oui.csv` 40,319 rows / 3.86 MB raw / 1.18 MB gzip; MA-M 6,628 rows; MA-S 7,226 rows. IEEE terms restrict redistribution (legal grey area).
- **Chrome theming:** `prefers-color-scheme` works in popups; Chrome does **not** expose browser theme/accent colors to extensions, so "follow Chrome theme" = auto light/dark with system colors. MV3 CSP forbids inline scripts; clipboard via `navigator.clipboard.writeText` under a user gesture needs no permission.

## 2026-10-09 — Decisions (user-confirmed)

1. **OUI data source = bundle offline.** Ship a compressed IEEE registry in the package. No host permissions, works offline, no third-party exposure. Accepted tradeoffs: larger package and IEEE license risk.
2. **Output formats = 3** — colon `AA:BB:CC:DD:EE:FF`, plain `AABBCCDDEEFF`, Cisco `AABB.CCDD.EEFF`. Windows/hyphen output explicitly excluded by the user.
3. **Scope = publish to Chrome Web Store.** Adds naming, privacy policy, packaging, and review readiness to scope.
4. **Theme = automatic light/dark** via `prefers-color-scheme`; no manual toggle. Chrome accent colors are not exposed, so the accent approximates Chrome blue.
